🔁 Daily Rules for Mastery

Rule 1: Code in C

Write solutions yourself rather than copying.

Rule 2: One problem deeply

It’s better to understand one problem than rush through five.

Rule 3: Revise every Saturday

Redo problems you previously struggled with.

Rule 4: Test every Sunday

Use a timer and avoid solution lookups.

Rule 5: Track your progress

Create a simple table:

Problem	Solved?	Complexity	Revision
Two Sum	✅	O(n)	Saturday
Valid Palindrome	⏳	—	Tomorrow
